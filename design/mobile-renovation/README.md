# 북썸 모바일 리노베이션

## 제품 기준

읽는 행동은 가볍게, 쌓이는 기억은 풍성하게.

- 첫 화면은 내 서재다. 지금 읽는 책에서 페이지 기록까지 바로 연결한다.
- 기록은 별도 목적지가 아니라 책에 하는 행동이다. 예전 `/record`, `/library` 주소는 호환한다.
- 책 이야기는 같은 책을 읽는 사람들의 공개 대화다. 개인 메모와 공개 게시를 구분한다.
- 나에서는 독서 활동을 돌아보고 프로필·계정을 관리한다. 북마켓·모임은 이곳에서 접근한다.
- 실제 데이터가 없으면 빈 상태를 보여준다. 예시 회원 수나 가짜 대화를 실제처럼 표시하지 않는다.

## 시각 기준

밝은 중립 바탕에 코랄을 한 가지 주색으로 쓰는, 가볍고 촉감 있는 개인 독서 공간.

- 바탕 `#FAF9F7`, 표면 `#FFFFFF`, 글자 `#262526`, 보조 글자 `#77716D`.
- 포인트 `#E75B40`, 포인트의 연한 면 `#FFE8DF`, 구분선 `#E9E5E1`.
- 조작부는 산세리프. 인용문만 기존 명조를 제한적으로 쓴다.
- 메인 화면에는 하나의 booksome 로고를 쓴다. 상세 화면은 뒤로가기·제목·행동으로 통일한다.
- 표지의 책등과 종이 단면은 유지하되 노란 종이 질감·초록 천·장식적 기울기는 제거한다.
- 입력 56px, 주요 버튼 52px, 터치 영역 최소 44px. 입력의 포커스·오류·비활성 상태를 제공한다.
- 기본 여백 24px, 버튼은 둥근 형태, 입력은 16px 모서리. 카드처럼 누르는 영역만 독립된 면을 쓴다.
- 썸디는 첫 시작과 빈 상태 등에 제한적으로 사용한다.

## 화면 구성

1. 내 서재: 로고·책 추가 → 제목 → 읽는 책과 오늘 읽었어요 → 읽는 중/완독/전체 → 책들.
2. 나의 책: 뒤로가기 → 표지·제목 → 읽은 페이지 조그셔틀 → 저장 → 문장·사진 기록 → 책 이야기 연결.
3. 책 이야기: 로고 → 용도 → 검색 → 책 목록 → 공개 대화. 검색 결과 없음·불러오기 실패를 구분한다.
4. 나: 로고 → 프로필 → 실제 서재 기반 활동 요약 → 독서 달력 → 프로필 편집·계정·기타 기능.
5. 인증·검색·스캔·모임·북마켓·작성·사진 편집: 같은 헤더·글자·입력·버튼 규칙을 사용한다.

## 상호작용 기준

- 하단 메뉴는 내 서재 / 책 이야기 / 나. 순서에 맞춰 좌우 이동하고 동작 줄이기를 존중한다.
- 조그셔틀은 좌우 드래그, ±1 조절, 직접 입력을 함께 제공한다. 총 쪽수를 몰라도 기록한다.
- 조그셔틀을 움직일 때 부모 스크롤을 잠근다. 저장은 명확한 버튼으로 확정한다.
- 저장 중 중복 제출을 막고 실패하면 입력을 유지한다. 완료 피드백은 실제 저장 결과만 표시한다.
- 버튼 눌림·페이지 조절·탭 전환의 움직임은 짧고 일관되게 한다.

## 구현 범위

Expo 모바일 앱과 동일 화면을 사용하는 웹 리더. 서버 API·저장 형식은 유지한다.
공개 Next.js 포털과 관리 콘솔은 이번 모바일 리노베이션 범위에 포함하지 않는다.
실제 표지와 사용자 데이터는 시안의 예시 도서·숫자·문장을 대체한다.

## 기존 API에 맞춘 처리

- 서버의 독서 진행률은 현재 위치다. 날짜별 독서량을 임의로 만들어내지 않는다.
- 독서 달력은 책 등록일과 실제 문장·사진 생성일을 보여준다.
- 검색 실패 시 ISBN·제목·저자를 직접 입력해 서재에 등록할 수 있다. 출처는 manual로 저장한다.
- 기록은 기본 비공개. 책 이야기에 쓰는 공개 글은 별도 행동이다.
- 기존 /library, /record 링크와 저장 데이터는 계속 사용할 수 있다.
