# 개인 독서노트와 공개 책 이야기

2026-10-10. 승인된 [두 화면 시안](approved-concept.png)을 기존 Next.js 포털에 구현했다. 이 작업은 `/library/[id]`와 `/rooms/[slug]`에 한정한다. 서재의 진행 중인 변경은 별도 작업으로 보존한다.

## 디자인 기준

- **개인:** 따뜻한 책 정보 사이드바 + 날짜·쪽수를 여백에 둔 독서노트 타임라인. 개인 기록에는 작성자 아바타·공감·댓글을 붙이지 않는다.
- **공개:** 가로형 책 정보 바 + 작성자 중심 대화 목록 + 들여쓴 답글 + 공개 작성창. 개인 쪽수·독서 진행률을 표시하지 않는다.
- 별도 책별 배경 이미지를 제작하지 않는다. 실제 표지가 있으면 쓰고, 없거나 로딩에 실패하면 제목과 책등 형태로 대체한다.
- 짧은 기록, 사진 없는 기록, 빈 목록도 같은 구성 안에서 동작한다. 예시 글·독자·통계를 실제 데이터처럼 채우지 않는다.
- 모바일에서는 개인 책 정보가 상단 요약으로 바뀌고, 공개 대화는 작성자·답글 흐름을 유지한다.

## 시안에서 실제 서비스에 맞춘 부분

- 기존 로고, 공통 메뉴, 로그인·로그아웃, `/study` 진입을 유지한다. 시안 속 가상 도메인·주소·사람·글은 제품에 넣지 않는다.
- 기록 제목 필드가 없는 현재 API에 맞춰 실제 문장·생각을 표시한다. 임의의 요약 제목을 생성하지 않는다.
- 공개 책과 개인 독서 책 ID가 동일하지 않으므로 공개 페이지의 개인 영역 링크는 정확하게 **나의 책 목록**으로 안내한다.
- **새 기록은 비공개**로 저장한다. 과거 공개 기록이 포함된 책은 상단에 ‘새 기록은 나만 볼 수 있어요’, 개별 기록에 ‘기존 공개 기록’을 표시한다. 수정으로 공개 범위를 바꾸지 않는다.
- 긴 공개 글은 ‘이야기 더 읽기’로 펼친다. 첫 답글을 미리 보여주며 전체 댓글과 작성창은 펼칠 수 있다.
- 공개 글 입력은 목록 아래의 작성창에서 한다. 상단 ‘공개 이야기 쓰기’가 입력창으로 이동한다. 비로그인 상태에서는 기존 로그인 복귀 경로를 유지한다.

## 구현과 데이터 경계

- `library-book.tsx`: 책 정보/문장 필터, 날짜별 기록, 읽은 위치 편집, 문장·생각·사진 작성, 수정·삭제.
- `room-discussion.tsx`: 공개 글, 댓글, 공감, 긴 글 펼치기, 오류 복구.
- `reading-dialog.tsx`: 네이티브 dialog의 포커스 관리, Escape 닫기, 저장 중 닫기 방지.
- `reading-experience.module.css`: 두 화면 전용 스타일. 다른 포털·입체 서재 스타일에 영향을 주지 않는다.
- `reading-icon.tsx`: 기존 선형 아이콘 방식의 작은 SVG 아이콘. 새 UI 라이브러리 의존성 없음.
- `book-cover.tsx`: 첫 화면의 책 표지에만 `loading="eager"`를 지정할 수 있게 추가. 나머지 표지는 기존 지연 로딩을 유지한다.
- 서버·스키마·인증 경계 변경 없음. HTTP-only 쿠키와 `/api/reader/**`를 통해 기존 Spring API를 사용한다.
- 사진 수정 시 원본 경로·네이티브 강조 표시 데이터·쪽수 스냅샷·공개 범위를 보존한다. 새 기록 작성창을 닫았다 다시 열면 같은 페이지에서 초안이 유지된다(새로고침·페이지 이동 후 영구 보관 기능은 아님).

## 로컬 검증

- 루트: `npm run typecheck`, `npm run test:reading` (11개 통과).
- web: `npm run typecheck`, `npm run lint`, `npm run test:portal` (74개 통과), `npm run build`.
- Chrome 실제 사용자 데이터: 개인 기록 11개가 있는 책, 기록 없는 책, 공개 글·댓글, 긴 글 펼치기/접기, 표지, 사진, 과거 공개 기록 안내. 운영 데이터는 읽기만 했다.
- 375px 모바일: 개인 책 요약/기록, 공개 대화/답글/작성창 확인, 가로 넘침 없음. 데스크톱 1512px에서도 확인.
- 운영과 분리한 loopback 테스트 API + Next standalone 산출물: 로그인 후 개인 책 복귀, 쪽수 저장, 완독/다시 읽기, 기록 생성/수정, 문장 필터, 실패 후 입력 유지 및 재시도, 작성창 Escape/초안 유지, 사진 메모 수정 시 원본 데이터 보존, 댓글 등록, 공감, 공개 글 등록, 목록 오류/재시도, 빈 상태, 세션 만료 및 재로그인 안내.
- 테스트 API와 데이터는 `/private/tmp`에만 두고 종료한다. 서비스 코드·운영 DB·공개 파일에 테스트 데이터나 우회 인증을 넣지 않는다.
- 개발 콘솔: HWP 브라우저 확장이 `<html>`에 추가한 속성으로 발생하는 hydration 경고와 기록 사진의 LCP 로딩 권고를 확인했다. 확장 설정이나 hydration 경고 숨김 처리는 추가하지 않았다.
- **검증 한계:** Chrome 확장 프로그램의 파일 URL 접근 권한 제한으로 파일 선택부터 업로드까지의 브라우저 검증은 완료하지 못했다. 기존 multipart 업로드 자동 테스트, 실제 사진 표시, 격리 데이터의 사진 메모 수정과 메타데이터 보존은 통과했다. 운영 기록 삭제는 실행하지 않았다.

운영 배포·커밋·푸시는 이 작업에서 실행하지 않는다.
