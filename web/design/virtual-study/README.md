# 가상 서재 — 로그인한 사용자의 책으로 채우는 원목 공간

2026-10-07. 로컬 주소: `http://localhost:3000/study`. 운영 배포는 하지 않았다. 이번 전환 전 작업은 `872801e`로 커밋했다. [이전 시안 기록](prototype-history.md)은 과거 자료이며 현재 구현 지침이 아니다.

## 현재 서비스 흐름

PC 상단과 모바일 메뉴의 ‘내 서재’ → `/study` → 개인 책 자동 불러오기 → 실제 책 클릭 → `/library/[id]`의 정보·독서 기록으로 연결한다. 책상 수첩과 투영된 ‘수첩 열기’ 표시, 하단 대체 링크는 기존 `/library` 목록으로 이동한다. 입체 서재에도 기존 로그인·로그아웃 컨트롤을 제공한다.

로그인 확인 전, 로그아웃 상태, 등록한 책이 없는 계정에는 빈 공간만 보인다. 런타임의 시안 도서와 ‘시안 보기/빈 서재’ 전환을 제거했고 `/study/books/demo-*` 상세 주소는 404다. 로딩·빈 목록·로그인 만료·서버 실패를 구분하고 로그인, 첫 책 등록, 다시 불러오기 동작을 제공한다.

`/api/reader/reading-life/books`에서 현재 계정의 전체 목록을 가져온다. 현재 API의 도서 상태는 `reading / finished`이며 읽는 중인 책을 우선한다. 앞표지·제목·저자·쪽수·상태는 저장된 도서의 값을 사용한다. 다른 프로필의 응답이 섞이면 표시하지 않고 새로고침을 안내한다. 로그아웃 시작·계정 변경·재조회 시 이전 책을 비우고 요청을 취소하며, 취소를 무시하고 늦게 도착한 이전 응답도 세대 번호로 차단한다. 탭 복귀와 뒤로 가기 복원에서도 재조회한다. 계정 도서를 localStorage에 저장하지 않는다.

책장 한 페이지에 최대 24권을 표시한다. 모든 책은 책등이 앞을 향하게 곧게 꽂고, 위쪽 칸부터 이웃한 책들을 모아 배치한다. 책을 꺼내는 깊이도 실제 책의 앞뒤 길이에 맞춘다. 칸의 높이가 낮으면 모든 축을 균일하게 축소해 표지 비율을 유지한다. 책이 많으면 이전/다음 책장으로 전체 목록을 볼 수 있으며 목록에서 다른 페이지의 책을 골라도 그 책장으로 이동한다. 읽는 책의 책상 표현은 같은 등록 도서의 추가 시점이며 새로운 도서/독서 기록을 생성하지 않는다. 실제 도서 수는 API 목록의 고유 항목 수다.

책장과 책상에 같은 도서가 표시되어도 각 메시의 UUID로 선택·움직임을 구분한다. 닫힌 책은 첫 클릭에 길이의 2/3만큼 꺼내고, 다른 책을 클릭하면 이전 책이 복귀한다. 나온 책의 두 번째 클릭은 실제 개인 상세로 이동한다. 펼친 책은 제자리에서 짧게 반짝인 뒤 한 번 클릭으로 해당 도서의 기록으로 이동한다. 펼친 책의 안쪽은 장식용 페이지 표현이며 도서 본문이나 사용자 기록을 재현한 것이 아니다.

## 표지 이미지와 인증 경계

모바일에서 사용자가 올린 표지를 포함해 `ReadingBook.externalCoverUrl`에 저장된 이미지를 그대로 선택한다. 검색 API를 다시 호출하거나 다른 판본의 이미지로 대체하지 않는다. 원본 책등 이미지는 제공되지 않으므로 책등은 실제 제목·저자와 표지에서 추출한 색·무늬로 만든다. 표지 전체의 세로 색 변화와 왼쪽 가장자리 무늬를 낮은 해상도로 섞어 표지 글자가 찌그러져 반복되지 않게 하고, 제목·저자는 명암 대비가 있는 글씨로 별도로 표시한다. 표지가 없는 책이나 이미지 실패는 제목을 표시하는 기본 표현으로 유지한다.

브라우저는 `/api/study/books/[id]/cover`를 요청한다. 서버는 HTTP-only 쿠키에서 세션을 읽고 Spring의 개인 도서 조회로 소유권을 확인한 뒤 해당 도서에 등록된 이미지만 가져온다. 로그인 없으면 401, 소유한 도서가 아니면 404다. URL을 쿼리 인자로 받아 임의 주소를 요청하는 경로가 아니다. 업로드 미디어는 통제된 `/api/media/{kind}/{owner}/{uuid}.{jpg|png|webp}` 경로로 내부 API에 전달한다. 외부 표지는 현재 사용하는 카카오/다음·네이버 이미지 호스트 및 국립중앙도서관 호스트만 허용하며 다른 호스트는 제목 표현으로 대체한다.

외부 이미지 요청에는 사용자 토큰·쿠키를 전달하지 않는다. 리다이렉트를 자동 추적하지 않고 8초 제한, 8MB 스트림 제한, JPEG/PNG/WebP 실제 파일 식별을 적용한다. HTML/SVG를 이미지 경로로 제공하지 않는다. 이미지 응답은 `private, no-store`, `Vary: Cookie`, `nosniff`를 사용한다. 브라우저와 모바일은 DB에 직접 연결하지 않는다. 기존 `/api/reader/**`, 로그인/가입/재설정, `/app/` 및 네이티브 인증 방식을 유지한다.

표지 바이트는 명시적인 same-origin 쿠키 요청으로 읽고 401일 때 기존 JSON 요청과 같은 세션 갱신을 공유한 뒤 재시도한다. 인증된 바이트만 임시 Blob URL로 디코딩하고 URL을 해제한다. 표지는 같은 도서의 책장·책상 표현에서 한 GPU 텍스처를 공유한다. 동시에 최대 3개를 읽고 384×576 캔버스 안에 비율을 유지해 담아 GPU 크기를 제한한다. 목록 교체·장면 해제 시 풀과 대기 작업을 정리하고 이전 이미지가 새 계정/새 목록에 적용되지 않게 한다. 사용자 이미지 파일과 개인 도서 JSON은 저장소에 저장하지 않는다.

`/study`는 `connection()`으로 요청 시 렌더링하고 noindex/private 캐시 설정을 적용한다. 개인 도서 데이터는 클라이언트의 쿠키 프록시 요청으로만 읽는다. 운영 배포에는 새 표지 Route Handler가 포함된 Next.js 서버 빌드가 필요하며 정적 페이지만 복사해서는 안 된다.

## 공간과 조작

원근 카메라와 제한 없는 Trackball 회전, 휠 확대, 화면 이동·방향키, ‘처음 구도’, 전체/책장/책상 시점을 제공한다. 기울어진 물체와 가져온 의자는 실제 변환 정점의 최저점으로 마루·러그 접점을 계산한다. 의자의 네 다리는 러그 왼쪽의 동일한 마루 면에 둔다. 바닥 액자는 두 원목 받침대로 지지한다. 화분·오토만·작은 의자·액자 사이에는 보수적인 경계상자로 간격을 둔다.

책상 소품은 책의 이동 도중에도 충돌을 검사해 책상 안의 가까운 빈자리로 밀려난다. 수첩 표시 메시와 빛 테두리는 충돌·클릭 판정에서 제외한다. 수첩은 약 6초마다 1.1초의 짧은 빛 효과를 보이고 호버/키보드 초점에서 강조된다. 실제 수첩이 가려지면 표시를 숨긴다. 모션 감소 설정은 정적인 강조를 사용한다.

렌더링은 상호작용·카메라 이동·재질 변화·짧은 안내 효과 중에 실행하고 효과 사이에는 쉰다. 숨겨진 탭의 타이머/렌더링을 멈춘다. 모바일 DPR 1.25, 800px 미만 후처리 생략을 유지한다. 해제 시 이벤트·타이머·GPU 자원을 정리한다.

## 검증 결과

루트 타입 검사·독서 테스트 11개, 웹 타입 검사·린트·테스트 40개·프로덕션 빌드가 통과했다. 빌드에는 기존 Expo `/app/` 내보내기가 포함된다.

Chrome 로그인 계정의 책 7권이 자동으로 표시되고 책장 7권·표지 로딩 7개·실패 0개·칸 경계 초과 0개를 확인했다. 사용자 업로드 사진인 E=mc2 표지와 외부 제공 표지를 모두 직접 확인했다. 책등 배치 후 책장 코스모스→넥서스의 선택/복귀 및 두 번째 클릭의 실제 기록 이동, 책상 넥서스의 독립 꺼내기, 펼친 호의에 대하여의 단일 클릭 기록 이동을 확인했다. 375px에서 실제 표지 목록→E=mc2 선택→상세 연결과 로그인/로그아웃 컨트롤 배치를 확인했다.

별도 `guest.localhost`의 프로덕션 화면에서는 기존 localhost 로그인 세션을 바꾸지 않고 책장·책상 도서 0개 및 로그인 안내를 확인했다. 인증 없는 개인 표지 HTTP 요청은 401, 이전 시안 상세는 404, 프로덕션 `/study` 헤더는 `private, no-store`/noindex였다. 마지막 재진입에서 이미지 요청의 401 재시도 누락을 발견해 수정하고 7개 표지가 다시 정상으로 로딩되는 것을 확인했다. 이 동시 바이트 요청의 세션 갱신·재시도도 회귀 테스트에 포함했다. 테스트는 빈 목록·다른 계정/늦은 응답·StrictMode 취소 후 재시작·로그인 만료·이미지 권한/MIME/용량/주소 검증, 실제 책장 칸에 두꺼운 책 24권이 책등 방향으로 겹치지 않고 모두 들어가는 것, 앞쪽 정렬·꺼내기 깊이와 표지 비율, 61권의 페이지 접근을 검증한다. 실제 계정에는 7권이므로 많은 책의 페이지 전환은 단위/기하 테스트로 확인했다.

운영 도서/이미지를 임의로 수정하거나 신규 테스트 도서를 등록하지 않았다. OS 모션 감소 변경, 실물 휴대전화 GPU/터치, 실제 다른 계정 로그인 전환은 직접 실행하지 않았다. Chrome HWP 확장 속성 주입에 의한 기존 hydration 경고는 별도다. 운영 배포는 하지 않았다.

## 에셋·현재 한계

[승인 시안](concept.png), 직접 만든 의자/담요 glTF와 Blender 원본, Image Gen 원목/직물/정원 이미지, Poly Haven CC0 재질/식물 모델을 유지했다. 출처와 재생성 명령은 [이전 작업 기록의 에셋 절](prototype-history.md#재질과-에셋-출처)에 있다. 에셋 서비스나 유료 키에 런타임 의존하지 않는다.

꾸미기 설정은 이 브라우저의 `booksome-study-settings-v1`에 저장한다. 가구를 직접 끌어 놓는 편집기, 계정별 가구 저장, 중력·낙하·전도 물리, 등록량에 따른 책장 증축, 실제 원본 책등 재현은 후속 범위다. 광선 추적/오프라인 렌더 수준의 전역 조명을 적용한 것은 아니며 가구/식물/간접광은 시안 사진과 차이가 있다.
