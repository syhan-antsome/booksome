# 가상 서재 — 나의 책과 풍경이 있는 공간

2026-10-08. 로컬 주소: `http://localhost:3000/study`. 운영 배포는 하지 않았다. 개인 책 전환 전 작업은 `872801e`로 커밋했다. [이전 시안 기록](prototype-history.md)은 과거 자료이며 현재 구현 지침이 아니다.

## 현재 서비스 흐름

PC 상단과 모바일 메뉴의 ‘내 서재’ → `/study` → 개인 책 자동 불러오기 → 실제 책 클릭 → `/library/[id]`의 정보·독서 기록으로 연결한다. 책상 수첩과 투영된 ‘책 목록’ 표시, 하단 대체 링크는 기존 `/library` 목록으로 이동한다. 입체 서재에도 기존 로그인·로그아웃 컨트롤을 제공한다.

로그인 확인 전, 로그아웃 상태, 등록한 책이 없는 계정에는 개인 도서가 없는 공간을 보이며 저장한 꾸미기는 유지한다. 런타임의 시안 도서와 ‘시안 보기/빈 서재’ 전환을 제거했고 `/study/books/demo-*` 상세 주소는 404다. 로딩·빈 목록·로그인 만료·서버 실패를 구분하고 로그인, 첫 책 등록, 다시 불러오기 동작을 제공한다.

`/api/reader/reading-life/books`에서 현재 계정의 전체 목록을 가져온다. 현재 API의 도서 상태는 `reading / finished`이며 읽는 중인 책을 우선한다. 앞표지·제목·저자·쪽수·상태는 저장된 도서의 값을 사용한다. 다른 프로필의 응답이 섞이면 표시하지 않고 새로고침을 안내한다. 로그아웃 시작·계정 변경 시 이전 책을 비우고 요청을 취소하며, 취소를 무시하고 늦게 도착한 이전 응답도 세대 번호로 차단한다. 같은 계정의 재조회는 현재 책을 유지한 채 백그라운드에서 확인하고, 목록의 내용과 순서가 같으면 기존 배열을 재사용해 책 모델·표지 텍스처·선택을 다시 만들지 않는다. 일시적인 연결 실패에도 현재 책과 재시도 안내를 유지하지만 로그인 만료·다른 계정 응답은 즉시 비운다. 탭 복귀와 뒤로 가기 복원에서도 재조회한다. 계정 도서를 localStorage에 저장하지 않는다.

책장 한 페이지에 최대 24권을 표시하며 소품이 차지한 칸은 책 자동 배치에서 제외한다. 공간이 부족하면 남은 책을 다음 페이지에 넣는다. 첫 페이지의 모든 칸을 소품으로 채운 뒤 새 책을 등록해도 소품은 유지하고 다음 페이지로 이어진다. 모든 책은 책등이 앞을 향하게 곧게 꽂고, 위쪽 칸부터 이웃한 책들을 모아 배치한다. 책을 꺼내는 깊이도 실제 책의 앞뒤 길이에 맞춘다. 칸의 높이가 낮으면 모든 축을 균일하게 축소해 표지 비율을 유지한다. 책이 많으면 이전/다음 책장으로 전체 목록을 볼 수 있으며 목록에서 다른 페이지의 책을 골라도 그 책장으로 이동한다. 읽는 책의 책상 표현은 같은 등록 도서의 추가 시점이며 새로운 도서/독서 기록을 생성하지 않는다. 실제 도서 수는 API 목록의 고유 항목 수다.

책장과 책상에 같은 도서가 표시되어도 각 메시의 UUID로 선택·움직임을 구분한다. 닫힌 책은 첫 클릭에 길이의 2/3만큼 꺼내고, 다른 책을 클릭하면 이전 책이 복귀한다. 나온 책의 두 번째 클릭은 실제 개인 상세로 이동한다. 펼친 책은 제자리에서 짧게 반짝인 뒤 한 번 클릭으로 해당 도서의 기록으로 이동한다. 펼친 책의 안쪽은 장식용 페이지 표현이며 도서 본문이나 사용자 기록을 재현한 것이 아니다.

## 표지 이미지와 인증 경계

모바일에서 사용자가 올린 표지를 포함해 `ReadingBook.externalCoverUrl`에 저장된 이미지를 그대로 선택한다. 검색 API를 다시 호출하거나 다른 판본의 이미지로 대체하지 않는다. 원본 책등 이미지는 제공되지 않으므로 책등은 실제 제목·저자와 표지에서 추출한 색·무늬로 만든다. 표지 전체의 세로 색 변화와 왼쪽 가장자리 무늬를 낮은 해상도로 섞어 표지 글자가 찌그러져 반복되지 않게 하고, 제목·저자는 명암 대비가 있는 글씨로 별도로 표시한다. 표지가 없는 책이나 이미지 실패는 제목을 표시하는 기본 표현으로 유지한다.

브라우저는 `/api/study/books/[id]/cover`를 요청한다. 서버는 HTTP-only 쿠키에서 세션을 읽고 Spring의 개인 도서 조회로 소유권을 확인한 뒤 해당 도서에 등록된 이미지만 가져온다. 로그인 없으면 401, 소유한 도서가 아니면 404다. URL을 쿼리 인자로 받아 임의 주소를 요청하는 경로가 아니다. 업로드 미디어는 통제된 `/api/media/{kind}/{owner}/{uuid}.{jpg|png|webp}` 경로로 내부 API에 전달한다. 외부 표지는 현재 사용하는 카카오/다음·네이버 이미지 호스트 및 국립중앙도서관 호스트만 허용하며 다른 호스트는 제목 표현으로 대체한다.

외부 이미지 요청에는 사용자 토큰·쿠키를 전달하지 않는다. 리다이렉트를 자동 추적하지 않고 8초 제한, 8MB 스트림 제한, JPEG/PNG/WebP 실제 파일 식별을 적용한다. HTML/SVG를 이미지 경로로 제공하지 않는다. 이미지 응답은 `private, no-store`, `Vary: Cookie`, `nosniff`를 사용한다. 브라우저와 모바일은 DB에 직접 연결하지 않는다. 기존 `/api/reader/**`, 로그인/가입/재설정, `/app/` 및 네이티브 인증 방식을 유지한다.

표지 바이트는 명시적인 same-origin 쿠키 요청으로 읽고 401일 때 기존 JSON 요청과 같은 세션 갱신을 공유한 뒤 재시도한다. 인증된 바이트만 임시 Blob URL로 디코딩하고 URL을 해제한다. 표지는 같은 도서의 책장·책상 표현에서 한 GPU 텍스처를 공유한다. 동시에 최대 3개를 읽고 384×576 캔버스 안에 비율을 유지해 담아 GPU 크기를 제한한다. 목록 교체·장면 해제 시 풀과 대기 작업을 정리하고 이전 이미지가 새 계정/새 목록에 적용되지 않게 한다. 사용자 이미지 파일과 개인 도서 JSON은 저장소에 저장하지 않는다.

`/study`는 `connection()`으로 요청 시 렌더링하고 noindex/private 캐시 설정을 적용한다. 개인 도서 데이터는 클라이언트의 쿠키 프록시 요청으로만 읽는다. 운영 배포에는 새 표지 Route Handler가 포함된 Next.js 서버 빌드가 필요하며 정적 페이지만 복사해서는 안 된다.

## 공간과 조작

원근 카메라와 휠 확대, 화면 이동·방향키, ‘초기화’, 전체/책장/책상 시점을 제공한다. 뉴욕은 Orbit 회전으로 내려다보기를 최대 30도로 제한하고 하늘 쪽 올려다보기는 최대 45도까지 허용한다. 좌우 회전은 제한하지 않는다. 다른 공간은 제한 없는 Trackball 회전을 유지한다. 기울어진 물체와 가져온 의자는 실제 변환 정점의 최저점으로 마루·러그 접점을 계산한다. 의자의 네 다리는 러그 왼쪽의 동일한 마루 면에 둔다. 바닥 액자는 두 원목 받침대로 지지한다. 화분·오토만·작은 의자·액자 사이에는 보수적인 경계상자로 간격을 둔다.

책상 소품은 책의 이동 도중에도 충돌을 검사해 책상 안의 가까운 빈자리로 밀려난다. 수첩 표시 메시와 빛 테두리는 충돌·클릭 판정에서 제외한다. 수첩은 약 6초마다 1.1초의 짧은 빛 효과를 보이고 호버/키보드 초점에서 강조된다. 실제 수첩이 가려지면 표시를 숨긴다. 모션 감소 설정은 정적인 강조를 사용한다.

렌더링은 상호작용·카메라 이동·재질 변화·짧은 안내 효과 중에 실행하고 효과 사이에는 쉰다. 숨겨진 탭의 타이머/렌더링을 멈춘다. 모바일 DPR 1.25, 800px 미만 후처리 생략을 유지한다. 해제 시 이벤트·타이머·GPU 자원을 정리한다.

## 내 서재 꾸미기

가구·집 구조는 고정하고 소품과 재질을 바꾼다. 포토스·다육이·작은 나무·고사리, 식물/노을/추상 액자, 곡선 도자기·아치·새·작은 우주·달, 버섯 조명·촛불의 14종을 제공한다. 모델·색상·아트 텍스처는 로컬 코드로 만들며 별도 외부 모델 서비스나 키가 필요하지 않다.

PC는 오른쪽 패널, 모바일은 하단 패널을 사용한다. 소품 탭에서 책장/책상을 고르고 각각 14가지/17가지 소품을 선택한다. 소품 선택 후 책과 다른 소품이 없는 칸이나 책상 자리만 강조한다. 보이는 칸의 투영 버튼 또는 네이티브 ‘빈 칸 목록’으로 배치할 수 있다. 가려진 칸의 투영 버튼은 숨긴다. 놓은 소품은 3D 클릭 또는 ‘놓은 소품’ 목록에서 골라 옮기기·90도 회전·색상 변경·치우기를 실행한다. 꾸미기 중 책 클릭은 독서 상세 이동을 실행하지 않는다. 현재 꾸미기는 미리보기이며 되돌리기·취소로 복원하고 저장으로 확정한다.

24개 책장 칸의 좌표/ID와 책 포장 계산은 공통 모듈에서 관리한다. 책장에 기본 화분·액자·조명·장식품을 만들지 않으며 모든 칸을 책이나 사용자 소품에 사용할 수 있다. 사용자가 배치한 소품이 있는 칸만 책 배치에서 제외한다. 이전 18개 칸의 ID와 좌표는 유지해 저장된 사용자 소품을 보존한다. 소품은 실제 변환된 정점의 경계상자로 모든 회전 방향을 칸 안에 맞추고, 최저점을 선반에 접지한다. 책의 모양·자리·표지가 동일하면 책 모델과 GPU 표지를 재사용하므로 빈 칸에 소품을 놓거나 색/질감을 바꿀 때 기존 책을 다시 만들지 않는다.

책상에는 `desk-layout.ts`의 4개 자리(왼쪽 뒤 작은 자리·왼쪽 앞·앞쪽 가운데·오른쪽 뒤)를 제공한다. 현재 책, 책 목록 수첩, 최근 책 묶음의 최대 꺼내기 경로와 책상 아래 책을 보호한다. 기본 스탠드·머그컵·연필꽂이·꽃병은 만들지 않고 독서 스탠드·머그컵·연필꽂이를 책상 전용 소품으로 제공한다. 기존 14가지 소품도 책상에 놓을 수 있다. 소품의 실제 경계상자를 자리 안에 맞추고 최저점을 상판 높이 1.89에 접지하므로 회전해도 책이나 다른 자리와 겹치지 않는다. 수첩은 책 옆의 고정 위치에 두고 소품이 움직이게 하지 않는다. 책상에 놓은 조명만 실제 광원을 가지며 추가 그림자 맵은 만들지 않는다.

저장은 기존 계정별 v2 문서의 `decorations` 배열을 사용한다. `desk-*` 자리 ID는 책상 소품이며 page는 항상 0으로 정규화한다. 같은 자리의 중복, 보호 영역 ID, 책상 전용 소품의 책장 배치를 거부한다. 책상 소품은 모든 책장 페이지에 같은 인스턴스로 표시하고 책장 칸이나 페이지 수를 소비하지 않는다. 공용 소품은 옮기기 중 책장/책상을 전환해 이동할 수 있다. 현재 책과 최근 책도 개인 책 목록 전체에서 가져오므로 책장 페이지를 바꿔도 책상 내용이 바뀌지 않는다. 기존 책장 칸 ID와 저장 방식은 유지하며 운영 API·DB·인증 경계는 변경하지 않는다.

‘색과 질감’ 탭은 분위기 조합 3개, 가구 색 4개, 벽 색 4개/질감 2개, 바닥 3개, 카펫 색/무늬 각 3개, 햇빛·기본 식물·카펫 표시·소품 색을 제공한다. 기존 PBR 결을 유지하고 페인트·헤링본·직조 패턴 변형을 장면별로 캐시한다. ‘초기화’는 카메라의 위치·회전·확대만 되돌린다. 둘러보기와 화면 이동 옆에 왼쪽/오른쪽 버튼이 강조된 SVG 마우스 그림을 표시한다.

설정과 배치는 로그인 계정별 `booksome-study-room-v2:{profileId}` 키에 이 브라우저의 localStorage로 저장한다. 기존 v1의 색/햇빛/식물 설정은 새 계정 설정이 없을 때 이관한다. 개인 책·표지 바이트·독서 기록은 이 저장 문서에 포함하지 않는다. 계정 전환은 편집 상태와 이전 방을 버리고 새 계정 설정을 읽는다. 잘못된 소품/칸/페이지/색/중복 값은 정규화하고 저장 실패는 미리보기를 유지하면서 오류를 안내한다. 로그아웃 상태에서는 미리보기를 제공하고 저장은 로그인으로 연결한다. 서버·다른 기기와 꾸미기 동기화는 아직 제공하지 않는다.

## 도시 속의 서재

‘꾸미기 → 풍경’에서 숲, 뉴욕, 도쿄, 런던을 비교한다. 뉴욕은 노을빛 스카이라인, 도쿄는 타워와 저녁 불빛, 런던은 시계탑·관람차·강변의 아침빛으로 구분한다. 배경은 내장 Image Gen으로 만든 실사풍 도시 이미지이며 현장 촬영 사진이나 정확한 지도 자료가 아니다. 서재·가구를 배경 이미지에 포함하지 않고 Three.js의 실제 3D 장면으로 별도 합성한다. 생성 프롬프트와 출처·최적화 방식은 [에셋 기록](scenery-prompts.md)에 있다. 런타임 외부 서비스나 새 API 키는 필요하지 않다.

뉴욕은 [승인된 펜트하우스 시안과 구현 기록](new-york-penthouse.md)에 따라 건물 안에 있는 방으로 표현한다. 테라스·통유리·기둥·돌 외벽·아래 여섯 층을 실제 3D로 연결한다. 책장 뒤쪽 아래층은 앞면처럼 창문·커튼·실내 깊이를 가지며 반대 측면은 기존처럼 창문 없는 외벽으로 막는다. 숲·도쿄·런던은 기존 방 구조를 사용한다. 기존 정원 이미지와 바닥 그림자 평면은 도시 모드에서 숨기고, 같은 배경이 실제 창 구멍과 유리 너머로 보이게 한다. 창문 안에 별도 사진을 넣지 않아 안팎의 풍경이 이어진다. 배경·창밖·햇빛 색·주변광·책상 조명이 함께 바뀐다. 사용자의 가구 재질·책·소품은 유지한다. 뉴욕 진입·복원처럼 공간 구조가 바뀌면 해당 전체 구도로 이동하며 다른 재질 변경은 회전/이동/확대 상태를 유지한다. 풍경 탭에 들어가거나 ‘서재와 풍경 함께 보기’를 누르면 전체 구도로 돌아간다. ‘초기화’는 선택한 공간의 첫 카메라 구도를 복원하며 풍경과 꾸미기를 바꾸지 않는다.

PC는 두 열 카드, 모바일은 네 가지 썸네일을 한 줄로 보여 서재 화면을 가리지 않고 비교한다. 키보드로 풍경 탭과 버튼에 접근할 수 있다. 풍경 선택도 기존 되돌리기·취소·꾸미기 저장에 포함되며 계정별 브라우저 저장을 사용한다. 이전 저장 문서에 풍경 값이 없거나 잘못된 값이면 숲으로 복원하고 나머지 재질과 소품은 유지한다.

선택한 도시의 환경 한 개만 유지한다. 뉴욕은 [360도 환경과 생성 기록](scenery-panorama.md)의 여섯 방향 큐브맵과 공통 구면 이미지를 사용해 실제 카메라의 회전·렌즈 확대를 함께 따른다. 면 경계에서는 공통 구면 이미지로 이어 색과 구름의 단절을 줄인다. 도쿄·런던은 1672×941 사진 판을 약 452~490 KiB로 제공하며 화면 비율에 맞춰 cover 크롭한다. 썸네일은 Next Image가 작은 크기로 최적화한다. 사진 환경은 개별 도시 건물의 깊이나 화면 이동 시 시차를 재현하지 않는다. 다른 도시로 바꾸면 이전 GPU 텍스처·연결 메시·재질을 해제하고 늦게 도착한 이전 요청은 적용하지 않고 해제한다. 숲 복원·장면 해제에도 같은 취소 경계를 적용한다. 같은 도시 선택은 재다운로드하지 않는다. 로딩과 실패를 안내하고 실패 시 다시 불러올 수 있으며 방과 책은 계속 이용할 수 있다. 기존 요청 시 렌더링, 숨겨진 탭 정지, 모바일 후처리 제한을 유지한다.

## 검증 결과

루트 타입 검사·독서 테스트 11개, 웹 타입 검사·린트·테스트 70개·프로덕션 빌드가 통과했다. 빌드에는 기존 Expo `/app/` 내보내기가 포함된다.

Chrome 로그인 계정의 책 7권이 자동으로 표시되고 책장 7권·표지 로딩 7개·실패 0개·칸 경계 초과 0개를 확인했다. 사용자 업로드 사진인 E=mc2 표지와 외부 제공 표지를 모두 직접 확인했다. 책등 배치 후 책장 코스모스→넥서스의 선택/복귀 및 두 번째 클릭의 실제 기록 이동, 책상 넥서스의 독립 꺼내기, 펼친 호의에 대하여의 단일 클릭 기록 이동을 확인했다. 375px에서 실제 표지 목록→E=mc2 선택→상세 연결과 로그인/로그아웃 컨트롤 배치를 확인했다.

별도 `guest.localhost`의 프로덕션 화면에서는 기존 localhost 로그인 세션을 바꾸지 않고 책장·책상 도서 0개 및 로그인 안내를 확인했다. 인증 없는 개인 표지 HTTP 요청은 401, 이전 시안 상세는 404, 프로덕션 `/study` 헤더는 `private, no-store`/noindex였다. 마지막 재진입에서 이미지 요청의 401 재시도 누락을 발견해 수정하고 7개 표지가 다시 정상으로 로딩되는 것을 확인했다. 이 동시 바이트 요청의 세션 갱신·재시도도 회귀 테스트에 포함했다. 테스트는 빈 목록·다른 계정/늦은 응답·StrictMode 취소 후 재시작·로그인 만료·이미지 권한/MIME/용량/주소 검증, 실제 책장 칸에 두꺼운 책 24권이 책등 방향으로 겹치지 않고 모두 들어가는 것, 앞쪽 정렬·꺼내기 깊이와 표지 비율, 61권의 페이지 접근을 검증한다. 실제 계정에는 7권이므로 많은 책의 페이지 전환은 단위/기하 테스트로 확인했다. 탭 전환·복귀를 반복하고 수동 새로고침도 실행해 같은 책 메시 UUID, 꺼낸 상태, 표지 로딩 7개와 카메라 구도가 유지되는 것을 확인했다. 백그라운드 조회 중·변경 없는 응답·일시 실패 후 재시도·변경된 목록의 적용도 회귀 테스트로 검증했다.

PC와 375×812에서 화분·액자·오브제를 배치하고 이동·회전·색 변경·치우기·되돌리기·취소, 저장 후 재진입, 빈 칸 목록과 놓은 소품 목록의 접근을 확인했다. 기본/아이보리·세이지·헤링본·줄무늬 조합의 실시간 미리보기를 확인했고 책 7권·표지 7개와 소품의 칸 겹침 0을 유지했다. 운영 도서/이미지를 임의로 수정하거나 신규 테스트 도서를 등록하지 않았다. OS 모션 감소 변경, 실물 휴대전화 GPU/터치, 실제 다른 계정 로그인 전환은 직접 실행하지 않았다. Chrome 확장의 inject.js/content.js에서 발생한 src/getTotalHeight 중복 선언 오류는 앱 코드와 별도다. 운영 배포는 하지 않았다.

2026-10-07의 도시 전환 검증에서는 로그인 상태의 책 7권·표지 7개·기존 소품 5개가 유지됐고 책/소품 겹침은 0이었다. 2026-10-08 사진 배경으로 교체한 뒤 Chrome PC 1440×900과 375×812에서 도시 선택·회전·확대·취소·숲 복원·초기화·창밖 연결과 가로 넘침 없는 표시를 확인했다. 현재 브라우저는 로그아웃 상태여서 개인 책을 만들어 넣지 않고 빈 서재의 풍경 미리보기와 로그인 후 저장 안내로 검증했다. 앱 자체 오류/경고와 기능을 막는 프레임워크 오류 화면은 없었다. 마지막 새로고침에는 확장이 html에 주입한 `data-hwp-extension`/`data-hwp-extension-version` 속성만 서버 HTML과 달라 hydration 경고 1건이 보였다. 출처도 chrome-extension의 installHook.js였으며 이를 숨기려고 앱의 hydration 검사나 확장을 변경하지 않았다. 추가 회귀 테스트는 PC/모바일 사진 비율, 방 모델 보존·같은 사진 재사용, 늦은 요청 차단·GPU 해제·실패 후 명시적 재시도, 풍경 값 정규화·되돌리기·계정별 저장을 검증한다. 실물 휴대전화 GPU/터치와 다른 브라우저는 이번에도 직접 실행하지 않았다.

2026-10-09. 책장의 기본 덩굴 화분 2개·액자 2개·버섯 조명 2개를 제거하고 소품의 전용 자리 6곳을 열어 전체 24개 칸을 책과 사용자 소품에 사용한다. 사용자 소품 저장 문서와 기존 칸 ID/좌표는 유지한다. 새 회귀 검사는 기본 방 장식이 책장 내부에 없고, 예전 18개 칸에 저장한 소품이 모두 복원되며 새 6개 칸을 책과 소품에 사용할 수 있는지 확인한다.

Chrome 1512×770과 375×812에서 로그인 계정의 실제 책 7권·표지 7개, 저장 소품 0개 상태를 확인했다. 꾸미기에서 빈 칸 23곳이 표시됐고 이전 기본 조명 자리인 큰 책장 3열·4단에 버섯 조명을 미리 배치해 소품 1개·책 겹침 0을 확인한 뒤 취소해 0개로 복원했다. 저장하지 않아 계정의 꾸미기 문서를 변경하지 않았다. 책장 집중 시점과 가로 넘침 없는 표시, 앱 오류 화면·콘솔 오류/경고 없는 상태를 확인했다. 웹 타입 검사·린트·빌드·테스트 66개와 루트 타입 검사·독서 테스트 11개가 통과했다. 실물 휴대전화 터치는 미검증이며 운영 데이터 수정·배포·커밋은 하지 않았다.

책상 꾸미기에서는 같은 Chrome PC·모바일 크기에서 스탠드·머그컵·연필꽂이·다육이를 네 자리에 미리 배치했다. 소품 4개·책 7권·표지 7개·충돌 0을 유지했고 표시된 자리 버튼과 자리 목록 선택을 모두 사용했다. 회전·색 변경·치우기·되돌리기, 빈 책상 자리로 옮기기, 공용 소품을 책장으로 옮겼다가 되돌리기, 모바일 배치 목록과 치우기·되돌리기를 확인했다. 취소 후 원래의 저장 소품 0개로 복원했으며 실제 계정에는 시험 배치를 저장하지 않았다. 저장/재열기와 기존 책장 소품 보존은 메모리 저장소를 사용하는 회귀 검사로 검증한다.

새 기하 검사는 17개 소품·4개 자리·4개 회전에서 상판 경계·기능 책/수첩·최근 책의 최대 꺼내기 경로와 겹치지 않는지 확인한다. 책상 전용 타입과 잘못된 자리·중복 자리 거부, 전체 개인 목록의 최근 책과 책상 소품이 책장 페이지 변경에도 유지되는 것, 저장·되돌리기·취소도 검사한다. 웹 타입 검사·린트·빌드·테스트 70개와 루트 타입 검사·독서 테스트 11개가 통과했다. 마지막 새로고침에서 검증 탭은 로그인 전 상태였으므로 로그인 후 실제 책 상세 이동의 추가 브라우저 재검증은 하지 않았으며 수첩의 `/library` 연결과 로그인 전 빈 상태를 확인했다. 실물 휴대전화 터치는 미검증이다. 운영 데이터·사용자의 저장된 꾸미기 변경, 배포·커밋은 하지 않았다.

## 에셋·현재 한계

[승인 시안](concept.png), 직접 만든 의자/담요 glTF와 Blender 원본, Image Gen 원목/직물/정원 이미지, Poly Haven CC0 재질/식물 모델을 유지했다. 출처와 재생성 명령은 [이전 작업 기록의 에셋 절](prototype-history.md#재질과-에셋-출처)에 있다. 에셋 서비스나 유료 키에 런타임 의존하지 않는다.

가구를 직접 끌어 놓는 편집기, 꾸미기의 서버 저장/기기 간 동기화, 사용자 사진 액자, 중력·낙하·전도 물리, 등록량에 따른 책장 증축, 실제 원본 책등 재현은 후속 범위다. 광선 추적/오프라인 렌더 수준의 전역 조명을 적용한 것은 아니며 가구/식물/간접광은 시안 사진과 차이가 있다.
