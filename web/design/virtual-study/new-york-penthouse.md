# 뉴욕 펜트하우스 구현 기준

> 이 문서는 2026-10-08의 구현 기록이다. 2026-10-09부터 도쿄·런던·서울·숲도 360도 환경과 연결된 공간을 사용한다. 현재 동작과 에셋은 [풍경 확장 기록](scenery-expansion.md)을 참고한다.

2026-10-08. [승인 시안](new-york-penthouse-concept.png)을 기준으로 기존 사용자 책과 꾸미기를 유지하는 실제 Three.js 건축 공간을 만든다.

- 시각 방향: 따뜻한 원목 서재가 석재·브론즈·통유리로 된 뉴욕 고층 주거 건물에 연결된 모습. 햇빛 방향과 외부 풍경을 맞춘다.
- 화면 구성: 기존 서재 캔버스/브랜드/책 목록·꾸미기 컨트롤을 유지한다. 왼쪽 테라스, 창틀, 구조 기둥과 바로 아래층 외벽으로 공간을 지지한다. 책과 소품의 칸 좌표는 유지한다.
- 재질: 시안의 밝은 회갈색 석재, 짙은 브론즈 창틀, 얇고 투명한 유리, 기존 PBR 원목과 직물. 기존 사용자가 선택한 가구 색/질감은 보존한다.
- 조작: 건물과 서재가 함께 회전·이동한다. 투명 유리는 책 클릭을 막지 않는다. 전체/책장/책상 시점 및 초기화와 책 꺼내기·기록 이동을 유지한다.
- 외부 풍경: [AI 실사풍 뉴욕 360도 환경](scenery-panorama.md). 펜트하우스와 일부 아래층은 입체이며 도시 전경은 사진으로 구성한 주변 환경이다. 카메라의 회전·확대를 함께 따르며, 전체 40층과 실제 지리 좌표·도시 건물의 시차를 재현하는 것은 아니다.

## 석재 에셋

`public/study/pbr/penthouse-stone-color.webp`: 내장 Image Gen으로 만든 무방향 석재 표면을 1024×1024 WebP quality 88로 최적화했다. 형상·조명은 실제 모델과 재질에서 적용한다.

```text
Use case: photorealistic-natural.
Asset type: seamless physically based architectural stone base-color texture for a luxurious New York penthouse facade in a Three.js virtual library.
Subject: one close-up flat orthographic surface of pale warm gray limestone/concrete cladding, softly weathered, fine mineral speckles and subtle natural mottling, elegant contemporary high-rise apartment facade material. Light gray taupe, nearly neutral with a hint of warm beige. Tiny pores and restrained irregular stone grain, no large veining.
Composition: square, evenly illuminated edge-to-edge, seamless tileable texture, uniform material scale. No perspective, panel outlines, seams, windows, buildings, room, cast shadows, directional highlights, ambient occlusion, text, logos or borders. This is solely a neutral diffuse/albedo material surface; lights and panel geometry will be rendered by the application. Photographic texture detail with realistic microscopic variation.
```

## 구현과 조작

`src/lib/study/penthouse.ts`는 기존 서재 옆에 테라스, 통유리, 브론즈 창틀, 석재 기둥, 천장과 아래 여섯 층을 연결한다. 책장 뒤쪽 아래층에도 앞면과 같은 창문·창틀·커튼·실내를 만들고, 반대 측면은 기존처럼 창문 없는 연속된 외벽으로 막는다. 아래층은 건축 깊이를 위한 비상호작용 주거 공간이며 사용자 책이나 독서 데이터를 생성하지 않는다. 기존 책장 칸과 책상 좌표는 유지하고 게시판만 뉴욕에서 뒤 벽으로 옮긴다. 창가 식물은 원래 위치의 원목 콘솔로 지지한다. 테라스 의자·탁자와 아래층 좌석·조명도 바닥/지지대에 연결한다.

도시 모드가 뉴욕일 때만 펜트하우스가 보인다. 숲·도쿄·런던에서는 기존 창문과 방 구조를 복원한다. 뉴욕 진입·다른 구조로 복원 시에는 해당 공간의 전체 구도로 이동한다. 같은 테마에서 재질이나 소품을 바꿔도 구도를 다시 만들지 않는다. 뉴욕 전체 구도는 건물 왼쪽 밖에서 실내와 테라스를 보는 방향이다. 책장·책상 시점과 화면 이동·광학 확대를 사용할 수 있다.

뉴욕은 `navigation-controls.ts`의 OrbitControls로 아래로 최대 30도 내려다보고 위로 최대 45도 올려다볼 수 있다. 과도한 탑다운 시야를 막으면서 하늘을 볼 수 있게 하고 수평선과 건물을 똑바로 유지한다. 좌우 회전은 제한하지 않는다. 확대·화면 이동·집중 시점·초기화에도 같은 경계를 적용한다. 책상 집중 시점은 약 28도로 제한 안에 들어간다. 숲·도쿄·런던의 기존 Trackball 회전은 유지하며 공간을 바꿀 때 이전 컨트롤의 이벤트를 해제하고 선택한 공간의 컨트롤로 교체한다. 꾸미기 취소와 풍경 복원에도 이 전환을 적용한다.

기본 구도는 천장 아래로 실내를 들여다보는 낮은 시선이다. 책장·책상 집중 시점과 1.2배를 넘는 확대에서는 앞쪽 보와 천장을 숨기는 건축 절개를 적용해 책을 가리지 않는다. 회전해서 시선이 천장 위에 놓일 때에도 천장을 절개한다. 유리 메시만 포인터 판정에서 제외하고 불투명 가구의 가림은 유지한다. 같은 유리는 GTAO의 노멀/깊이 렌더링에서도 제외해 가구의 접점 그림자를 보존한다. 제외한 표시 상태는 렌더링 예외가 나도 finally로 복원한다. 아래층에는 추가 그림자 맵을 만들지 않는다. 화면 크기가 바뀌면 렌더러와 후처리의 DPR을 함께 조정하고 작은 화면에서는 후처리를 생략한다.

## 시안 비교

| 비교 항목 | 반영 내용과 한계 |
| --- | --- |
| 건물에 연결된 방 | 아래층 외벽·슬래브·기둥과 같은 3D 그룹으로 연결했다. |
| 왼쪽 테라스 | 실내 바닥 높이에서 이어지는 석재 바닥, 유리 안전 난간, 의자·탁자·식물을 배치했다. |
| 통유리와 창틀 | 왼쪽·앞·오른쪽을 투명 유리와 브론즈 프레임으로 둘렀다. 유리를 통해 책과 빈 칸 버튼을 선택한다. |
| 기존 원목 서재 | 책장·책상·의자·담요·카펫·화분을 재사용한다. 사용자가 저장한 색/재질을 덮어쓰지 않는다. |
| 뉴욕 풍경과 빛 | 실사풍 배경, 낮은 노을빛, 창틀 그림자와 실내 접점 그림자를 연결했다. |
| 조작을 위한 절개 | 기본 구도는 천장이 닫혀 있다. 확대·집중 시점·천장 위에서 내려다보는 회전에서는 천장을 절개한다. |
| 현실감의 범위 | 도시와 석재는 AI 실사풍 에셋이다. 주변의 다른 방향은 사진 기반 환경으로 표현하지만 정확한 지리 좌표·도시 건물별 시차·전체 40개 층은 재현하지 않는다. 실시간 조명과 기존 모델의 세부 형태는 시안의 오프라인 렌더와 차이가 있다. |

기존 브랜드·내 서재·꾸미기·책 추가·책 목록·초기화·조작 컨트롤은 유지한다. 풍경 선택의 설명은 ‘맨해튼의 펜트하우스 서재’로 바꾸고, 기존의 ‘도시 위에 떠서’ 안내는 도시 선택 안내로 고쳤다. 시안에 앱 UI가 없으므로 기존 조작 컨트롤을 유지하는 것은 의도적인 차이다.

## 로컬 검증

Chrome의 실제 로컬 `/study` 화면을 승인 시안의 1536×1024 크기와 모바일 375×812에서 검증했다. 시안과 최종 렌더 이미지를 모두 view_image로 열어 건물 지지·테라스·통유리·서재 배치·빛·조작 절개의 비교 항목을 확인했다. 회전·화면 이동·최대 확대 3.6·초기화, 모바일의 다육이 배치·회전·색 변경·치우기·되돌리기·취소, 취소 후 기존 방과 구도 복원을 확인했다. 가로 넘침·책상/바닥 소품 충돌·책/소품 칸 겹침은 0이었다.

웹 typecheck·lint·테스트 62개·프로덕션 build와 루트 typecheck·독서 테스트 11개가 통과했다. 추가 기하 테스트는 실제 책 모델 7개의 책등을 향한 포인터가 집중 구도와 앞 유리를 통해 해당 책에 도달하는 것, 구조 슬래브와 하부 층, 비상호작용 건축물에 가짜 독서 도서가 없는 것, 공간별 기본 카메라를 검증한다. 이 7권은 테스트 안의 fixture이며 운영/화면에 등록하지 않았다. 카메라 회귀 테스트는 반복된 큰 회전 입력·여러 바퀴 좌우 회전·화면 이동·확대 범위에서 상하 경계와 upright 상태, 세 집중 시점의 도달, 공간별 컨트롤 및 조작 모드 전환을 검증한다.

검증 브라우저는 로그아웃 상태여서 실제 계정의 책 클릭·상세 이동과 계정 저장 재확인은 이번 브라우저 검증에서 실행하지 않았다. 계정별 저장·소품 보존·개인 도서 인증 경계는 기존 회귀 테스트가 통과했다. 실물 휴대전화 GPU/터치는 미검증이다. Chrome 확장이 html에 주입한 data-hwp-extension 속성의 hydration 경고 1건은 앱 오류와 구분했다. 경고를 숨기거나 확장 설정을 변경하지 않았다. 운영 서버/DB 변경·배포·커밋은 하지 않았다.

같은 날 추가한 상하 시야 제한은 Chrome 1512×770과 375×812에서 로그인된 계정의 실제 책 7권·표지 7개·기존 소품 5개로 확인했다. 반복 드래그의 상한/하한은 각각 polar 1.047/1.484 rad(수평선 위 30/5도)였고 upY는 1을 유지했다. 상한에서 좌우 회전, 확대 3.6에서도 상한 유지, 화면 이동 후 시야 각도 유지, 책장/책상 집중 시점과 초기화, 도쿄의 기존 자유 회전 및 꾸미기 취소 후 뉴욕 복원을 확인했다. 모바일 크기에서 가로 넘침은 없었다. 저장된 꾸미기나 운영 도서·독서 기록을 변경하지 않았다. 실물 터치와 다른 브라우저는 이번에도 미검증이다. 최종 검사에서 앱 오류 화면과 앱/셰이더 오류는 없었고 위의 확장 hydration 경고만 있었다.

이후 사용자 피드백에 따라 올려다보기 경계를 5도 내려다보기에서 45도 올려다보기로 열었다. 탑다운 상한 30도는 유지한다. PC 1512×770과 모바일 크기 375×812에서 위쪽 드래그로 polar 2.356 rad(45도 올려다보기)에 도달해 하늘이 보이고, 반대 드래그는 기존 polar 1.047 rad에서 멈추며 초기화도 기존 구도로 복원하는 것을 확인했다. 가로 넘침과 앱 오류 화면은 없었고 이번 콘솔 점검에서 오류/경고는 없었다. 웹 62개·루트 11개 테스트, 웹/루트 타입 검사, 웹 린트·빌드가 통과했다. 실제 휴대전화 터치는 미검증이며 운영 데이터와 저장된 꾸미기는 변경하지 않았다.

2026-10-09. 화면 이동으로 서재를 상단까지 올린 뒤 회전할 때 하단의 끊어짐이 드러나는 것을 줄이기 위해 아래층을 3개 추가했다. 기존과 같은 층 높이·창문·기둥·실내 깊이를 갖는 총 6개 층과 7개 층 바닥을 만들고 뒤/옆 외벽도 전체 높이로 연장한다. 하단은 약 -21.49까지 이어진다. 기존 서재·카메라 범위·책/소품 좌표는 유지하며 아래층에는 그림자 맵이나 사용자 도서를 추가하지 않는다.

Chrome 1512×770과 1536×1024에서 화면 이동으로 targetY=-0.35까지 올린 다음 최소 확대 0.65에서 30도 내려다보기·45도 올려다보기·좌우 회전을 확인했다. 확인한 구도에서 건물 끝이 화면 아래로 이어졌다. 추가 투영/가림 테스트는 같은 상단 이동 상태에서 3개 가로 화면 크기·24개 회전 방향·4개 상하 각도를 검사한다. 375×812에서도 책 7권·표지 7개·소품 5개·가로 넘침 0을 유지했다. 세로 화면이나 다른 화면 이동 조합에서 모든 건물 끝을 가리도록 보장하는 구현은 아니다. 웹 타입 검사·린트·빌드·테스트 63개와 루트 타입 검사·독서 테스트 11개가 통과했다. 실물 휴대전화 터치는 미검증이다. 앱 오류 화면과 앱/셰이더 오류는 없었고, 기존 Chrome 확장의 HTML 속성 주입에 따른 hydration 경고는 별도로 확인했다. 운영 데이터 수정·배포·이번 변경의 커밋은 하지 않았다.

같은 날 책장 뒤쪽 아래층의 연속된 외벽을 창문이 있는 입면으로 바꿨다. 앞면과 같은 방 모델을 뒤로 회전해 6개 층에 24개 창문과 창틀·커튼·좌석·조명의 깊이를 연결한다. 반대 측면은 사용자 설명에 따라 처음처럼 창문 없는 외벽으로 막고 6개 층 전체 높이로 이어지게 한다. 상단 서재의 책장 뒤 벽은 유지한다. 추가 그림자 맵이나 독서 데이터는 생성하지 않는다.
